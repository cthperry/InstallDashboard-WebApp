# F46 修正摘要

## 已修改
- 裝機案表單驗證失敗時，新增欄位就地錯誤顯示。
- 日期欄位錯誤改為直接顯示在對應欄位下方。
- 客戶、機型、區域、階段、工程師、機台序號也支援欄位錯誤顯示。
- 儲存失敗時，按鈕區上方新增固定錯誤摘要區，不再只放表單最上方。
- 送出驗證失敗時，會自動捲動並聚焦到第一個錯誤欄位。
- 關閉表單、重新開啟表單、成功送出前，會清空前一次錯誤狀態。
- 欄位內容一旦被修改，會清除該欄位舊錯誤，並清空底部摘要，避免殘留誤導。

## 已做靜態檢查
- 檢查 `DashboardWorkspace.tsx` 修改區段語法與 JSX 結構。
- 檢查提交失敗流程仍維持 `installationSchema.safeParse -> collectFieldErrors -> focusInstallErrorField` 單一路徑。

## 需要你實機驗證
1. 在表單下半部製造日期先後錯誤，按儲存後是否直接看到欄位紅字。
2. 按儲存後，畫面是否會自動移到第一個錯誤欄位。
3. 底部「取消 / 儲存」上方是否會出現錯誤摘要區。
4. 修正欄位後再次儲存，錯誤是否清除且可正常存檔。
