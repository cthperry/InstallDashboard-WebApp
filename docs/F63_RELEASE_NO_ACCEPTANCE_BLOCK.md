# F63 修正：裝機轉量產不再卡驗收日期

## 本次修正
- 正式量產不再強制要求「驗收完成日期」。
- 裝機轉量產仍維持既有契約：序號必填、工程師必填、安裝開始後需有實際安裝日期。
- 匯入預覽與提示文案同步改正，不再把「驗收完成日期」當成轉量產前提。

## 保留規則
- 正式量產 + 有序號：移出裝機案件，轉入設備台帳。
- 同序號設備不可同時存在裝機案件與設備台帳。
- 驗收完成日期若有填，仍會寫入資料並用於設備里程碑 prodStart。

## Root cause
先前把「正式量產」與「驗收完成日期」綁成同一個必要條件，導致狀態切到 released 時，validation 仍硬卡 actComplete。這和既有案件生命週期不一致。
